# Pic Visuals (Fabric 1.21.4)

Клиентский мод: ESP (Glass 3D), nametag, HUD, меню.

- `H` — открыть/закрыть меню
- Конфиг: `config/pic_visuals.json`
- Размытие фона в меню: Options -> Video Settings -> Menu Background Blur (поставь побольше)

## Сборка на GitHub
1. Залей все файлы в репозиторий (папка `.github` обязательна).
2. Вкладка **Actions** -> **Build mod** -> дождись зелёной галочки.
3. Внутри запуска внизу **Artifacts** -> `pic_visuals-jar` -> скачай jar.
4. Положи jar в `.minecraft/mods` вместе с Fabric API 0.119.2+1.21.4.
